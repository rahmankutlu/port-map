# Support

Port Map is maintained as an open-source project on a best-effort basis.

- Use [GitHub Discussions](https://github.com/rahmankutlu/port-map/discussions) for setup questions, workflow ideas, and general conversation.
- Use the [bug report form](https://github.com/rahmankutlu/port-map/issues/new?template=bug_report.yml) for reproducible defects.
- Use the [feature request form](https://github.com/rahmankutlu/port-map/issues/new?template=feature_request.yml) for scoped product proposals.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities. Do not disclose security issues publicly.

Before sharing screenshots or exports, remove management addresses, MAC addresses, serial numbers, hostnames, and other environment-specific information.
